## Result

Not started. Filled by the assigned worker; submission fields are defined in the protocol.
Status/date; baseline/full diff; matrix coverage; commands/exit codes/pass-fail-skip,
dependencies/logs, protected hashes, reuse/reasons for reruns; risks/unverified items;
remaining work/processes and saved WIP links; map proposals and a lesson candidate: scope/condition/action/evidence/limitations.
Task resources: path/branch/process, owner, state, and necessary preservation, or "none"/unknown.
Time/cost/model must be observed values with source and scope, or unknown.
Extract counters from logs; do not rerun the suite for formatting. The issued checker remains mandatory.

## Acceptance

Not performed. Orchestrator only:

- Full first review; list of ID/reproduction/impact/required outcome/check and finding category.
- After rework: delta, previous findings, and affected connections; broaden review according to risk.
- Before another substantive return: recurrence cause, preserved WIP/evidence, and selected approach.
- Decision/date, accepted version, integrated version/joint checks or a specific prerequisite.
- Returns/reasons, repeated checks/reasons, confirmed reuse, report corrections without falsifying Result.
- Available time/cost through integration with source/scope; do not estimate unknowns.
- Lesson: accepted/rejected with reason; local location/source and status, without automatic global promotion.
- cleanup: done or pending; remainder/reason, owner, next action/recheck condition; retained resources need purpose, retention condition, and access/recovery. No resources: done — no temporary resources were created.
- Affected memory facts and links updated; historical packages preserved; environment changes checked specifically.
- New independent scope goes to PLAN; critical risk blocks acceptance. Release is separate.
