# Canonical plan

Template. During installation, fill from the current request and existing sources, preserving open task IDs.
If an active plan exists, use it and adapt links instead of creating a second plan.

| ID | Outcome and criterion | Dependencies | Priority | Status | Task record / evidence |
| --- | --- | --- | --- | --- | --- |

Statuses: draft → ready → running → review → accepted → integrated.
Blocked denotes a specific obstacle, not completion. Review means worker submission;
accepted means the orchestrator's decision; integrated means verified incorporation of the result.
External release is tracked separately and does not follow automatically from integrated.
