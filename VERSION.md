# OCMI 2.0.0

One release number covers the native core and all work, personal and coordinator
profiles in both languages. OCMI 2.0 combines selected file memory with native
task/resource lifecycle, scoped code context and Git/WIP checkpoint recovery.

A native home separates public payload in `system/`, selected portable memory in
`OCMI_Sync/` and machine-only state in `local/`. Begin with a verified matching
ReadyKit, bind the client project and initialize the coordinator before opting
into a personal topic or work project.

After explicit binding, `context.inspect` provides current operational facts and
scoped originals. It does not replace semantic planning, required whole inputs,
explicit assignment or acceptance. Installed projects adopt changes by an
explicit preserving update, retaining local rules, language, evidence and WIP.

[Release guide](docs/releases/2.0.0.md) · [Start](BOOTSTRAP.md) ·
[Installation](docs/install-system.md) · [Changelog](CHANGELOG.md).

Functional capability does not establish effectiveness on every real task or
measured time/token savings. Client permissions and supported provider boundaries
still apply.
