# OCMI 2.0.0

One release number covers the system and all work, personal and coordinator profiles in both languages.
The 2.0.0 candidate aligns native verified-home entrypoints with the bilingual profiles.
After explicit native binding, `context.inspect` can provide fresh operational facts; it does not
replace START, readiness, approval, semantic planning, or required whole inputs.
Installed projects adopt changes by an explicitly requested merge preserving local rules, language,
tasks, protected evidence and WIP. File instructions do not fix client hangs or enforce cloud isolation.

[Release guide](docs/releases/2.0.0.md) · [Start](BOOTSTRAP.md) ·
[Installation](docs/install-system.md) · [Changelog](CHANGELOG.md).

Native capability remains a candidate pending pilot and platform acceptance; it does not establish
universal enforcement, measured savings, or release readiness.
