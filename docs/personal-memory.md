# Personal topic memory

[English](personal-memory.md) · [Русский](../locales/ru/docs/personal-memory.md)

Personal storage is optional after core setup. Ask the coordinator to create a topic at an agreed
location, including an undecided subject; existing installed topics continue without reinstalling.
The self-contained [topic guide](../templates/personal/memory/GUIDE.md) covers new chats/AI systems,
move/merge, stale facts, archive and selective cloud transfer. It is installed inside each topic.

Examples: “Create an undecided topic”; “Continue this topic in another chat”; “Merge these two
specified topics, preserving sources”; “Prepare only this topic for transfer, without uploading it”.
Name the selected folder(s); a store index/link does not authorize reading every topic.
Keep one writable current copy, resolve sync conflicts explicitly and preserve unfinished work.
Files and relative links are portable; client permissions, cloud sharing and automatic memory need
separate verification. Synthetic file checks do not certify isolation across AI/cloud providers.
