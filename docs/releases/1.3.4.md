# OCMI 1.3.4 — diagnostics, selected skills and code context

Release date: 2026-10-16. [English](1.3.4.md) · [Русский](../../locales/ru/docs/releases/1.3.4.md).

This release packages the first four roadmap stages: evaluation method, scoped diagnostics,
task-selected skills/optional specialists and scoped code context. One version covers the full
system and every current en/ru profile. Personal-profile behavior is unchanged apart from the label.

- Ask the installation coordinator to check an explicitly selected OCMI installation/task.
  It runs supported read-only diagnostics and explains facts, issues, unknowns and one next step.
  No user commands/JSON, automatic repair or readiness/acceptance authority.
- Five portable skills: search-first, causal CI triage, test design, review and security review.
  Read catalog metadata first, then selected bodies. Optional specialist functions retain one
  orchestrator/task owner and consolidated acceptance; no automatic agents/chats/models or native install.
- CODEMAP/rg guides explicit file selection; optional PowerShell helpers return current fingerprints,
  outlines and reference candidates within a context budget. Mandatory inputs go first; missing/omitted
  evidence remains explicit. Session-only outlines are invalidated by content/root/revision/engine changes.
  PowerShell uses AST function outlines; Go/JS/TS/Python/Rust and reference matches are lexical candidates,
  not a full semantic dependency graph. Unsupported capabilities use scoped manual fallback.
- Evaluation separates actual measurements from unknowns. Synthetic context reduction is observed;
  live discovery quality and whole-task token/time/cost savings remain unmeasured.

## Install or adopt

First setup still uses the full repository: local source → bound client project → separate confirmed
coordinator. Personal storage and project integration remain optional after handover.
[Setup](../install-system.md) · [Diagnostics](../doctor.md) · [Code context](../context.md).

The [six-profile receipt](1.3.4.json) verifies work 30, personal 6 and coordinator 8 files per language.
New work installation includes all guides and skill catalog/bodies; tools are optional. Existing
projects need an explicit merge preserving local rules/language, active tasks, protected checks, WIP
and private data. Old packages/receipts and previous release refs stay immutable.
The release does not update installed projects or change client/global settings.

## Verification and limits

[Release acceptance](../memory/tasks/OCMI-RELEASE-030/HANDOFF.md) records source validation and delivery
requirements. check-all covers bilingual guards, exact ZIPs, boundary fixtures, diagnostics, skill
selection and code retrieval; native CI requires Windows plus macOS Apple Silicon and Intel.
Privacy/secret scanning includes indexed public files, extracted ZIPs and reachable history.
Instructions are not an OS sandbox, and selected context is not completeness or permission.
Publication is verified separately against protected main, CI, tag, downloaded source and asset hashes.
