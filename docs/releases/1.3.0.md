# OCMI 1.3.0: optional guided setup

**English** · [Русский](../../locales/ru/docs/releases/1.3.0.md)

Released locally: 2026-10-12. Publication is a separate action.

## Result

[BOOTSTRAP](../../BOOTSTRAP.md) gives downloaded-checkout and GitHub-URL entry paths.
The first interaction explains OCMI and offers independent choices. It does not write,
scan targets, rename folders, clone sources or install profiles without a selected action.
Direct requests already selecting an action do not need repeated authorization.

Root AGENTS separates setup orientation from development. The optional coordinator
profile stores only setup choices and nonsensitive installation metadata outside the
source checkout/public Git scope. Existing setup records are merged at their current paths.
Personal storage is optional, including for a persistent coordinator.

English/Russian [coordinator distributions](../../releases/README.md) contain seven
self-contained files each, including MIT. The [receipt](1.3.0-validation.json) records
source/ZIP inventories, bytes, SHA256 and all previous archive hashes.

## Compatibility and validation

System version 1.3.0 is an additive minor release. Work 1.2.2 and lightweight 1.2.1,
their templates, previous releases, task schema and active assignments remain unchanged.
No installed project or personal store is migrated by updating the source.

Check docs, workflow, localization, onboarding, release contents and git diff.
Onboarding checks include negative mutations for lost authority/privacy clauses and
unsafe/missing inputs. Source/ZIP equality and historical hashes are checked separately.
See the [acceptance record](../memory/tasks/OCMI-ONBOARD-013/HANDOFF.md) for actual outcomes.
New [behavioral scenarios](../evals/context-recovery.md) remain not run; structural checks
do not prove that every client follows the route or that token costs decrease.

After an authorized coordinator installation, resume from its local AGENTS and handoff.
Source development continues in docs/memory. Folder moves, chat management, global
settings, publication and project upgrades remain separately selected actions.
