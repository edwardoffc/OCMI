Выберите один язык. Существующий проект обновляется явно с сохранением местных правил и WIP.

[Исходный единый receipt](../../../docs/releases/1.3.3-unified.json) и все прежние архивы остаются неизменными.

Выберите язык и распакуйте профиль целиком. Языковые комплекты содержат [MIT](../../../LICENSE).
