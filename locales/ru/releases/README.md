# Установочные комплекты

[English](../../../releases/README.md) · **Русский**

Выберите язык и распакуйте профиль целиком. Новые языковые комплекты содержат [MIT](../../../LICENSE).
Рабочий протокол — 1.2.2, облегчённый — 1.2.1. Установленные проекты автоматически не обновляются.

Система [1.3.0](../VERSION.md) начинается со [знакомства и выбора](../BOOTSTRAP.md).
Комплект координатора скачивается только после выбора постоянной памяти настройки;
личное хранилище и внедрение в рабочие проекты не обязательны. Это не полный исходник системы.

Первоначальные commit/tag могут отсутствовать в отдельной публичной поставке.
