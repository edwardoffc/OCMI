# Структура ОКПИ

[English](../../../docs/layout.md) · [Русский](layout.md)

Разработка исходника и установленная папка — отдельные деревья.

~~~text
source-checkout/                 только разработка
  docs/ templates/ runtime/ scripts/

00_OCMI/                          проверенная распакованная папка установки
  .ocmi-home.json  SHA256SUMS
  system/                         неизменяемая публичная система и bin/ocmi[.exe]
  OCMI_Sync/
    coordinator/                  выбранные плоские переносимые файлы
    personal/                     отсутствует до явного выбора
    recovery/                     отсутствует до выбранного восстановления
  local/
    state/ bindings/ cache/ runs/ состояние конкретной машины
~~~

`system/**` — проверенная публичная часть. `OCMI_Sync/coordinator` содержит только переносимые смысловые входы без привязки устройства или подтверждения. `local/**` исключён из публичной проверки и передачи. Не превращайте checkout исходников в папку установки, не восстанавливайте всю папку рекурсивно и не переносите занятую установку без явного маршрута.

Совместимое обновление проверенная внешняя кандидатная программа применяет
только к публичной системе выбранной папки. `OCMI_Sync` и `local` остаются на
месте; это не замена всей папки, перенос прежних данных или автоматическая
перезагрузка. См. [обновление установки](install-system.md#обновление-установленной-папки).
