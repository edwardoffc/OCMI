# Установка ОКПИ

[English](../../../docs/install-system.md) · [Русский](install-system.md)

## Канонический маршрут установки

1. Получите или переиспользуйте проверенный подходящий ReadyKit. Ссылка или
   скачанный исходный код служит для знакомства и получения подходящего
   комплекта, но не является установленной папкой исходников.
2. Проверьте контрольную сумму по доверенной записи архива, затем распакуйте комплект в новую пустую
   выбранную папку установки. Публичная часть находится в `system/`, а
   единственный исполняемый файл — `system/bin/ocmi[.exe]`. Не изменяйте
   занятую, неизвестную или частично подготовленную папку.
3. Выполните `ocmi install --home ABS` (либо проверку без записи
   `ocmi install --home ABS --inspect`). Команда создаёт только объявленную
   машинную инфраструктуру в `local/` и корень `OCMI_Sync`.
4. Координатор установки выполняет `ocmi coordinator prepare --home ABS
   --language en|ru --client-project NAME`. Команда создаёт
   `local/bindings/coordinator/STARTUP.md` и плоские переносимые файлы
   `OCMI_Sync/coordinator/{coordinator.json,AGENTS.md,INDEX.md,HANDOFF.md}`.
5. Пользователь создаёт или переиспользует проект клиента, привязанный к этой
   папке, открывает отдельный чат координатора и отправляет сгенерированный
   стартовый промпт.
6. Координатор читает плоские файлы и локальную привязку, проверяет текущую
   связь проекта инструментами или текущим подтверждением пользователя, затем
   записывает явные локальные сведения через `ocmi coordinator confirm --home ABS
   --client-project NAME --evidence-source user-current|client-tool --evidence TEXT`.
   `ocmi coordinator inspect --home ABS` только читает.
7. Только после подтверждения передачи роли координатор предлагает личное
   хранилище или внедрение в проект; ничего из этого не создаётся автоматически.

Команда записывает сообщённые сведения, но не доказывает сама личность чата
или интерфейс клиента. Не копируйте в новую папку старое доверие клиента,
базу данных, квитанцию, стартовый промпт или подтверждение. Действующие прежние
установки сохраняются как входы совместимости; перенос выполняется только
отдельно выбранным маршрутом. Никогда не публикуйте архив установленной папки.
