# Индексация кода и сборка контекста в выбранной области

[English](../../../docs/context.md) · [Русский](context.md)

Попроси оркестровщика проекта: «Найди реализацию для этой задачи и собери нужный контекст». Он
восстановит назначение, проверит CODEMAP, поищет в выбранной области и соберёт определения,
кандидатов обращений и нужные обязательные контракты/тесты. Пользователю не нужны команды и JSON.
Координатор установки может объяснить этот способ; доступ/интеграция в проект требуют подходящего
запроса и собственного назначения установленного проекта.

Самодостаточное [рабочее руководство](../templates/work/docs/guides/context.md) входит в комплект
вместе с двумя необязательными помощниками PowerShell в tools/. Разработка базы использует идентичные
файлы из scripts/. Они не сканируют репозиторий и не угадывают обязательные файлы: агент явно выбирает
пути через CODEMAP/rg и задачу. Сервис, установка зависимостей и автоматическое обновление проектов не нужны.

Для сессии агента/инструмента (PowerShell 7 на Windows/macOS; нативный абсолютный путь выбранного корня):

~~~powershell
. ./scripts/context-lib.ps1
$context = Invoke-OCMIContext -Root (Get-Location).Path `
  -Files scripts/context-lib.ps1,scripts/ocmi-context.ps1 `
  -RequiredFiles docs/memory/RULES.md -Terms Invoke-OCMIContext -BudgetChars 16000
$context | ConvertTo-Json -Depth 10
~~~

CLI scripts/ocmi-context.ps1 принимает те же параметры, возвращает JSON и код 0 для выбранных кандидатов
или 2 при неполноте/неверных входах. Передавай массивы из PowerShell-сессии: обработка аргументов -File
в оболочке может не сохранить массив через запятые. Вызовы библиотеки держат кэш структуры в памяти;
отдельные процессы CLI строят заново. Загружаемого/сохраняемого на диск кэша нет.

Каждый выбранный файл заново читается и проверяется SHA256 при каждом запросе, включая WIP.
Происхождение содержит точную область/содержимое, переданный SourceRevision (по умолчанию unknown,
это не подтверждённая Git-идентичность) и версию инструмента/среды. Смена корня/ревизии/инструмента
отменяет повторное использование; изменённые файлы разбираются заново, записи вне последней успешной
области исчезают. Экономится разбор и контекст, не чтение диска. После новых правок нужна перепроверка;
снимок не атомарный. Исходники не сохраняются в индексе, но выдача и имена могут быть приватными.
Они не записываются и не экспортируются автоматически.

Обязательный текст идёт целиком первым; пропуски бюджета/ошибки разбора/ограничения явные. selected
означает, что найденные кандидаты поместились, а не полноту зависимостей или готовность. Агент должен
проверить закреплённые входы, функции целиком и вызовы/контракты/тесты, расширив чтение при пробелах.
Пределы, исключённые каталоги, неподдержанные форматы и ручной запасной путь — в рабочем руководстве.

## Выбор способа разбора

Пилот использует встроенный AST PowerShell для функций и явно лексические кандидаты Go/JS/TS/Python/Rust.
Это не требует новой среды и автоматической установки, но не даёт семантических межъязыковых связей.
Помощники написаны для ОКПИ; сторонний код не копировался.

| Вариант | Возможности / цена | Решение |
| --- | --- | --- |
| CODEMAP + rg + помощник сессии | Места в выбранной области, свежие снимки, без сервера; лексические пробелы остаются | Переносимый пилот по умолчанию с ручным запасным путём |
| [Tree-sitter](https://github.com/tree-sitter/tree-sitter/blob/master/LICENSE) | Структура синтаксиса; binding/грамматикам нужны свои версии и проверка лицензий | MIT ядра проверена 2026-10-16; грамматики/binding не выбраны и не импортированы |
| [Serena/SolidLSP](https://github.com/oraios/serena/blob/d9e4c796fae0207ba6848d1df4b331122a5567b5/LICENSE) | Определения/обращения через сервер языка; среды, активация и процессы | Проверены уведомления закреплённых компонентов: SolidLSP MIT, приложение GPL-3.0-or-later; код/адаптер не установлен |
| [Карта Aider](https://github.com/Aider-AI/aider/blob/5dc9490bb35f9729ef2c95d00a19ccd30c26339c/aider/repomap.py) | Синтаксические метки и ранжированный граф с бюджетом; зависимости разбора/графа | Изучен подход Apache-2.0; реализация не импортирована, граф не источник полномочий |

Семантический адаптер стоит выбирать позже под доказанный пробел языка, с точным корнем, проверкой
возможностей/лицензии и текущими полномочиями установки. Неподдержанные/косвенные связи сейчас неизвестны.
Личный поиск не включён; выбранная тема сохраняет собственные корни и разрешения.

check-context проверяет определения/вызовы/контракты/тесты, правки с прежним mtime, смену области/ревизии/
инструмента, переименование/удаление, переполнение обязательных входов, кодировку/размер/пути/ссылки,
настоящий CLI и исходники базы. Он включён в check-all и существующую Windows/macOS-матрицу. Сокращение
символов на fixture сравнивается с полным текстом той же области; реальные токены/деньги/время не измерены.
