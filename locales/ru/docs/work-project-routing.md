# Нейтральное правило рабочего проекта

Система OCMI 1.3.2. Это выбор процесса, а не личный профиль или назначение разработки.
Используй в необязательных общих инструкциях клиента с явно заданным путём системы.
Не устанавливай глобальное правило автоматически.

Когда пользователь обозначает конкретный проект как рабочий («это рабочий проект» или равнозначно),
выбирай оркестровщика/исполнителей/консультанта на чтение, файловую память и карту кода.
Обсуждение фразы как примера не назначает текущую папку рабочим проектом.

1. Определи состояние цели только по действующим инструкциям и указанному входу ОКПИ.
   Обычный AGENTS.md или незаполненный шаблон не доказывают действующую установку.
2. Действующая установка использует свои инструкции, память и текущие задания.
   Не навязывай координатора, не перезаписывай шаблонами, не дублируй PLAN и не обновляй без просьбы.
3. Каждую новую установку выполняет настроенный координатор установки.
   Проверь явные пути системы/службы, проект клиента/привязку и текущее подтверждение запуска/handoff.
   Если этого нет или оно не подтверждено, отложи внедрение и передай запрос координатору.
   Не копируй профили, не создавай память и не изучай код/тесты до выполнения условий.
4. Для базовой настройки читай только BOOTSTRAP.md, VERSION.md, README выбранного языка и необходимые
   нейтральные руководства/шаблоны. Не читай docs/memory, INDEX/PROFILE исходника или личные темы.
   Объясни получение/переиспользование системы, привязку проекта и запуск координатора.
5. Подтверждённый координатор использует templates/work/INSTALL.md выбранного языка.
   Сохрани исходные отложенные цель/область; уже разрешённые действия не требуют повторного разрешения.
   Уточняй недостающие пути; недоступный источник не разрешает сканирование диска и соседних областей.
6. Разрешение внедрения в цель не выбирает неуказанные базовые папки и не разрешает настройки клиента,
   чаты/сообщения, модели, фоновые действия, публикацию или production. Текущие указания пользователя важнее.
   Пути источников и указатели не разрешают доступ и не наследуют политику других проектов.

После внедрения цель использует свою память в обычной работе.
Новая лёгкая тема имеет то же базовое условие в templates/personal/INSTALL.md.
Инструкции задают процесс; они не запрещают ручное копирование и не обеспечивают изоляцию файлов.
