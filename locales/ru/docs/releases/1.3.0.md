# OCMI 1.3.0: настройка по выбору

[English](../../../../docs/releases/1.3.0.md) · **Русский**

Локальный выпуск: 2026-10-12. Публикация — отдельное действие.

## Результат

[BOOTSTRAP](../../BOOTSTRAP.md) описывает вход через скачанную копию и ссылку GitHub.
Первый разговор объясняет OCMI и предлагает независимые варианты. Без выбранного
действия нет записи, изучения назначений, переименования, клонирования или установки.
Прямой запрос с выбранным действием не требует повторного разрешения.

Корневой AGENTS разделяет знакомство и разработку. Необязательный профиль координатора
хранит выбор настройки и нечувствительные метаданные установок вне исходника/публичного Git.
Существующие записи согласуются на прежних путях. Личное хранилище необязательно,
в том числе для постоянного координатора.

Английский/русский [комплекты координатора](../../releases/README.md) содержат по семь
самостоятельных файлов, включая MIT. [Receipt](../../../../docs/releases/1.3.0-validation.json)
фиксирует состав исходников/ZIP, байты, SHA256 и хеши всех прежних архивов.

## Совместимость и проверки

Версия системы 1.3.0 — совместимое минорное обновление. Рабочий 1.2.2 и лёгкий 1.2.1,
их шаблоны, прежние выпуски, формат задач и текущие назначения не менялись.
Обновление исходника не переносит проекты или личные хранилища.

Проверяются документация, рабочий процесс, локализация, знакомство, состав выпусков и git diff.
Проверки знакомства включают негативные мутации потери правил полномочий/приватности
и небезопасных/отсутствующих входов. Равенство исходников/ZIP и прежние хеши проверяются отдельно.
Фактические результаты — в [приёмке (английский)](../../../../docs/memory/tasks/OCMI-ONBOARD-013/HANDOFF.md).
Новые [сценарии поведения](../evals/context-recovery.md) пока не запускались; структурные
проверки не доказывают соблюдение маршрута каждым клиентом или снижение расхода токенов.

После разрешённой установки координатор продолжает по своим локальным AGENTS и handoff.
Разработка исходника остаётся в docs/memory. Перенос папок, управление чатами, глобальные
настройки, публикация и обновления проектов выбираются отдельно.
