# Система OCMI 1.3.2

Дата: 2026-10-12. Область: единая установка по ссылке или скачанной копии.
Рабочий профиль остаётся 1.2.2, лёгкий — 1.2.1.

Первый чат выдаёт конкретные шаги с папкой, проектом клиента и координатором.
Первый запрос внедрения сохраняется как отложенная область до подтверждения базовой настройки.
Скачанная копия и подходящий привязанный проект переиспользуются.
Для завершения нужны локальный исходник, служебная память, подтверждённая связь проекта/папки
и запущенный координатор. Источник подтверждения — инструменты либо текущее подтверждение пользователя;
предложение, историческая запись или непривязанный чат не завершают установку.
Координатор затем объясняет использование и предлагает необязательные личные/рабочие действия.

Профиль добавляет CLIENT_PROJECT как шестое поле промпта и сохраняет восемь файлов каждого языка.
Два ZIP координатора и четыре новых ZIP компонентов имеют отдельные имена. Оба INSTALL
и нейтральное правило рабочего проекта требуют подтверждённого координатора для новых установок.
Рабочие файлы протоколов и установленные проекты не меняются; установочные инструкции обновлены.
Все 19 архивов/контрольных файлов до этого дополнения неизменны, включая подготовленные ZIP координатора.
Пользовательские записи остаются вне исходника/публичного Git.

Обязательные структурные проверки, локализация, архивы и приватность записываются в приёмке.
Сценарии E31–E39 подготовлены, не запускались; статические проверки не доказывают привязки клиента или поведение модели.
Публикация GitHub требует соответствующего разрешения и отделена от локальной приёмки.
