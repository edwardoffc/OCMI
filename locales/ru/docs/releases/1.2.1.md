## Результат

Один основной контекст задачи, владельцы/срок по событию для временных ресурсов,
короткая проверка завершения главным и отдельный cleanup: done/pending в Acceptance.
Подробности находятся в процедуре оркестровщика; маршрут ролей остаётся коротким.
Нет нового журнала, фоновой уборки или автоматического удаления. Полномочия не расширены.
Защищённые пакеты/checkers, WIP/evidence и три заголовка карточки сохранены.

## Разбор сценариев завершения

Это ручная проверка непротиворечивости инструкций на вымышленных ситуациях.
Реальные ресурсы не удалялись; поведение модели/инструмента удаления не тестировалось.

| Ситуация | Решение по правилам 1.2.1 |
| --- | --- |
| Малая правка без временных ресурсов | Прежний контекст; после интеграции done с отметкой «ресурсы не создавались» |
| Результат принят, но ещё не интегрирован | Приёмка сохраняется, полное закрытие не объявляется; ресурсы нужны до интеграции |
| R2 и пригодная копия R1 / чужая активная копия | Свою использовать повторно; чужую не занимать; изменение baseline требует ревизии |
| Untracked/ignored, неизвестный WIP или открытый finding | Не удалять неизвестное; сохранить уникальное/evidence; pending либо обоснованный keep |
| Основная копия/другая задача использует временный путь | Сохранить ресурс и зависимость; перед закрытием устранить её и проверить затронутую среду |
| Общий cache или воспроизводимая сборка | Общий cache сохраняется; воспроизводимость сборки подтвердить до разрешённого удаления |
| Squash/cherry-pick, есть только SHA | Проверить фактическую интеграцию и доступность данных/истории; SHA не считается резервной копией |
| Штатное удаление отказало / нет разрешения | Не переходить к force; pending с причиной, владельцем и нужным решением |
| cleanup pending, затем изменена среда/config | Приёмка не отменяется; повтор затронутого check, а не полный suite ради отчёта |
| Старый пакет без cleanup или ссылка на закрываемую копию | Статус неизвестен; пакет неизменен, актуальное решение/маршрут восстановления в текущей памяти |
