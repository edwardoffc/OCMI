# Windows и macOS

[English](../../../docs/platforms.md) · **Русский**

На обеих платформах настройка одинакова: локальная папка системы → привязанный проект клиента →
подтверждённый координатор → необязательное личное хранилище и внедрение в проекты.
Вход по ссылке и по скачанной копии приводит к этому результату. Если клиент не умеет привязывать
папку или читать файлы, установка остаётся ожидаемой; установщик выдаёт недостающие ручные шаги.
См. [установку](install-system.md).

Используй пути своей платформы: например, `C:/Work/00_OCMI` в Windows или `~/Projects/00_OCMI` в macOS.
Установщик раскрывает `~` в выбранный абсолютный путь в приватных стартовых записях.
Служебная память на обеих платформах хранится в `.local/coordinator` внутри системы,
исключается из Git и публичных архивов и сохраняется при обновлении. Личное хранилище необязательно.
Имена файлов профилей, выбор языка, роли и входы восстановления одинаковы.

Для обычной файловой установки и использования PowerShell не требуется: агент использует доступные
файловые/Git-инструменты либо выдаёт ручные шаги. Не запускай удалённые скрипты только для установки
системы Markdown. Доступные действия по-прежнему зависят от клиента и его разрешений.

## Разработка исходника

Установи Git и [PowerShell 7](https://learn.microsoft.com/en-us/powershell/scripting/install/install-powershell).
На обеих платформах запускай из корня репозитория:

~~~powershell
pwsh -NoProfile -File scripts/check-all.ps1
~~~

В macOS `pwsh` работает нативно на Intel и Apple Silicon. Windows PowerShell 5.1 проверяется
отдельно для совместимости с Windows и не является зависимостью macOS. Для проверки секретов
также нужен проверенный бинарник Gitleaks под операционную систему и процессор.
См. [проверки](../scripts/README.md).

CI запускает все проверки документации и приватности на Windows, macOS Apple Silicon (`macos-15`)
и Intel (`macos-15-intel`). Обязательные итоговые проверки отклоняют результат, если любая платформа
завершилась ошибкой или была пропущена. Общие проверки путей используют системные разделители,
учитывают регистр границ области в Unix, отклоняют симлинки и ограничивают уборку временными
папками текущего запуска. Искусственные примеры проверяют пробелы, Unicode, опасные пути,
исключение служебной памяти и работу скопированных скриптов. Приватная память и содержимое
установленных проектов для этого не нужны.

Эти проверки подтверждают поведение исходника на раннерах; они не тестируют интерфейсы всех
ИИ-клиентов, качество восстановления моделями или экономию токенов. Поддержка платформы также
зависит от выбранного клиента и среды выполнения.
