# Личная память тем

[English](../../../docs/personal-memory.md) · [Русский](personal-memory.md)

Личное хранилище необязательно и предлагается после базовой установки. Попроси координатора создать
тему в согласованной папке, в том числе неопределившуюся; установленной теме не нужна переустановка.
Самостоятельное [руководство темы](../templates/personal/memory/GUIDE.md) описывает другой чат/ИИ,
перенос/объединение, устаревшие факты, архив и выборочную облачную передачу. Оно устанавливается внутри темы.

Примеры: «Создай неопределившуюся тему»; «Продолжим тему в другом чате»; «Объедини эти две указанные
темы с сохранением источников»; «Подготовь только эту тему к переносу, ничего не загружая».
Назови выбранную папку/папки; индекс/ссылка не разрешает чтение всех тем хранилища.
Храни одну текущую изменяемую копию, явно согласуй конфликты синхронизации и сохраняй незавершённое.
Файлы и относительные ссылки переносимы; права клиента, облачный доступ и автоматическую память
проверяют отдельно. Синтетические проверки файлов не сертифицируют изоляцию между ИИ/облаками.
