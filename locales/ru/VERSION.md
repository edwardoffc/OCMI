# OCMI 1.3.4

Один номер выпуска обозначает систему, координатора, рабочий и личный профили на обоих языках.
Выпуск добавляет диагностику через координатора, выбор навыков/необязательных специалистов и
сборку контекста кода. Поведение личного профиля прежнее; номер выпуска общий для всех профилей.

Установка, полномочия ролей, Contract/Result/Acceptance и защищённые назначения совместимы.
Проекты принимают изменения только по явному запросу с сохранением местных правил, языка, задач
и WIP. Даты правил, хеши исходников и ревизии задач описывают происхождение, не отдельные версии.
