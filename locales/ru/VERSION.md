# OCMI 1.3.2

Выпущена 2026-10-12. Исправление: единый вход по ссылке/копии и явные условия завершения.

Первый чат кратко знакомит с системой и предлагает установку.
После выбора нужна локальная копия системы и подготовка заполненного стартового промпта.
Привязанный проект клиента содержит координатора; привязка и запуск требуют подтверждения.
Первые просьбы внедрения откладывают работу с целью до завершения базовой настройки.
Личное хранилище, организация папок и внедрение в проекты необязательны после запуска.

| Компонент | Версия |
| --- | --- |
| Система и сценарий установки | 1.3.2 |
| Служебный профиль координатора | 1.3.2 |
| Рабочий протокол | 1.2.2 |
| Лёгкий протокол | 1.2.1 |

Рабочий/лёгкий протоколы не меняются; проверки INSTALL и примечания рабочего VERSION теперь требуют
новых установок через координатора. К двум комплектам координатора добавлены четыре новых ZIP компонентов.
Все ранее выпущенные архивы неизменны.
Установленные проекты, личные хранилища и привязки клиента не переносятся автоматически.
