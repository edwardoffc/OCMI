# OCMI 1.3.3

Дата выпуска: 2026-10-13. Совместимое исправление процесса: короткие карточки малых задач, достаточные проверки и причинный разбор сбоев.

| Компонент | Версия |
| --- | --- |
| Система | 1.3.3 |
| Служебный профиль координатора и политика установки | 1.3.2 |
| Рабочий протокол | 1.2.3 |
| Облегчённый протокол | 1.2.1 |

Полный/короткий формат выбирается по риску; scope, защищённые входы, обязательные проектные проверки и приёмка сохраняются.
Существующее покрытие проверяется до добавления тестов; перед дорогим CI выполняются подходящие дешёвые проверки.
Успешный повтор сам по себе не устраняет сбой. Повторная доработка требует сохранённых доказательств и изменённого способа диагностики.
При проверенном продолжении читаются изменившиеся записи; новый чат восстанавливает обязательные входы.

Установка сохраняет общий путь по ссылке/копии, локальную систему, привязанный проект клиента и настроенного координатора.
Служебная память остаётся в .local/coordinator, исключённой из Git/export.
Личное хранилище, организация папок и внедрение в проекты необязательны после запуска.
Два новых рабочих ZIP дополняют неизменные комплекты координатора 1.3.2-r2 и лёгкого профиля 1.2.1-r2.
Прежние архивы/контракты неизменны. Установленные проекты автоматически не обновляются.
Windows/macOS используют одинаковый процесс; новые изменения требуют проверки нативного CI при публикации.
