# Поиск кода и сборка контекста задачи

Используй, когда для поиска реализации/зависимостей или восстановления задачи пришлось бы читать
много файлов целиком. Пользователь может просто попросить оркестровщика проекта найти нужный код
и собрать контекст задачи; пути и инструменты выбирает агент. JSON, сервис индекса и новый чат не нужны.

1. Сначала восстанови роль/назначение/рабочую копию, текущий START и закреплённые входы. Оркестровщик
   использует текущий запрос и нужную память. Индекс не выбирает работу, не даёт доступ и не заменяет START.
2. Прочитай нужные строки CODEMAP; проверь пути, символы и снимок. Через rg --files в выбранной области
   и поиск буквальных имён найди определения, вызывающий код/импорты, контракты, тесты и fixtures.
   Исключай служебные/личные и генерируемые каталоги. Не перечисляй соседние проекты и личные хранилища.
3. Выбери явные файлы в разрешённой области, имена идентификаторов и обязательные входные файлы.
   Необязательный tools/ocmi-context.ps1 вернёт текущие хеши, кандидатов определений/обращений и
   ограниченные фрагменты. tools/context-lib.ps1 даёт Invoke-OCMIContext в сохранённой PowerShell-сессии.
   Каждый запрос читает и хеширует выбранные файлы; неизменённые структуры можно брать из памяти сессии.
4. Перед выводом или правкой прочитай затронутые функции и нужные вызовы/контракты/тесты. По мере
   необходимости ищи новые имена/импорты. Лексический поиск находит и комментарии/одноимённые сущности;
   динамические, косвенные вызовы и псевдонимы может пропустить. Фрагмент указывает место, а не всю связь.
5. RequiredFiles попадают целиком перед необязательными фрагментами. Если обязательный файл/фрагмент
   не помещается, верни incomplete и пропущенные пути/строки; увеличь бюджет или отдельно прочитай
   необходимые доказательства в разрешённой области. Бюджет не отменяет защищённые входы и проверки.
   Нет совпадения, ошибка разбора, неподдержанный формат и усечённый поиск не доказывают отсутствие/полноту.
6. Пути/снимки и оставшиеся пробелы записывай в существующие входы START/Result; второй журнал не нужен.
   Предлагай только затронутые исправления CODEMAP; оркестровщик проверяет и принимает их. После правок
   и перед повторным использованием перепроверь исходники. Неизвестную полноту указывай явно.

Помощник работает через PowerShell 7 на Windows/macOS; Windows PowerShell 5.1 также проверяется.
Функции PowerShell разбираются встроенным AST. Структуры объявлений Go, JS/TS, Python и Rust, а также
все обращения — лексические кандидаты, без разрешения компилятором/LSP. Другие разрешённые текстовые
контракты/конфиги можно указать обязательными входами. Только UTF-8. Внешних серверов и зависимостей нет.

Ограничения: 128 записей выбранных/обязательных путей, восемь имён, 128 КиБ/файл, 2 МиБ чтения,
16 384 строки/файл, 512 символов/файл, 512 окон обращений, 128 совпавших записей структуры.
Превышение входов останавливает запрос; ограниченные результаты остаются incomplete. BudgetChars
(по умолчанию 16 000; 128–131 072) ограничивает символы исходников, не токены и не весь JSON/отчёт.
Метаданные ограничены отдельно. RequiredFiles берутся из назначения; помощник не угадает забытые критерии.

Индекс — удаляемая память сессии с корнем, ревизией, версией инструмента и хешами содержимого.
WIP проверяется и при прежнем mtime; после переименования/удаления нужно заново выбрать пути, не угадывать.
Кэш хранит только последнюю успешную область. Нет дискового кэша, переписок, поиска между проектами,
vector/SQLite и фоновой индексации. Clear-OCMIContextCache очищает его; новый процесс строит заново.
Метаданные и исходники могут быть приватными: не коммить/публикуй сырую выдачу и не включай её в комплекты.
Это ограниченный снимок, не атомарная транзакция и не изоляция ОС. Явный выбор и исключённые имена
не находят все секреты; агент обязан соблюдать границы доступа и данных текущей задачи.

Если PowerShell/помощник недоступен или формат не поддерживается, используй проверенную CODEMAP,
ограниченный rg и ручное чтение строк, назвав недоступную возможность. Tree-sitter/LSP/Serena можно
позже оценить для реального пробела языка; не устанавливай/активируй их и не ищи другие корни автоматически.
