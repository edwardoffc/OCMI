## Профиль среды

Одно место: эта таблица либо ссылка на существующий runbook; Contract ссылается на нужные строки.
Версия клиента, toolchain и используемые команды проверяются отдельно от разрешений.
Не записывать секреты и значения ключей; профиль не выдаёт полномочия и не включает hooks сам.

| Возможность / команда и cwd | Клиент / версия / условия | Состояние | Дата и evidence |
| --- | --- | --- | --- |

Состояние: настроено / доступно / проверено / unavailable / unknown; это разные утверждения.
Записанная конфигурация не доказывает выполнение. Hooks/инструменты включать только при реальной потребности.
Изменение клиента, разрешений, runner/зависимостей делает затронутое evidence требующим проверки.
Для памяти обязателен ручной путь через AGENTS и handoff; hook не единственный способ продолжения.
