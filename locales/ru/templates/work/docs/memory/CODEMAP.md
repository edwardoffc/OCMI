# Карта входов в код

Шаблон, не готовый индекс. Заполняет оркестровщик только по проверенным исходникам.

| Область / задача | Файл и символ / точка входа | Связанные callers, контракты и checks | Источник проверки | Актуальность |
| --- | --- | --- | --- | --- |

Источник проверки: дата + commit/snapshot или fingerprint файлов области + ссылка на check/исходник.
Актуальность: verified для названного снимка, needs-check при затронувшем изменении; unknown для пробела.
Одна отметка о карте целиком не подтверждает все строки. Начни с областей текущих задач.
Rename, интерфейс, schema/config, caller или test/check требуют проверки связанных строк, не всей карты.

Исполнитель получает нужные строки; сверяет путь/символ, ищет адресно через rg и читает актуальный код.
При пробеле расширяет поиск внутри разрешённого scope: нужны также callers, contracts, tests и fixtures.
Неполный поиск/недоступный вход не означает отсутствия символа. Не ограничивай полноту числом файлов/проходов.
Предложение исправления и evidence — в Result; общую карту обновляет оркестровщик.
Номера строк необязательны; карта помогает найти источник и не доказывает поведение.

Для ограниченного поиска символов/контекста и ручного запасного пути при необходимости используй
[руководство по контексту](../guides/context.md). Удаляемый индекс не заменяет проверенную карту и входы назначения.
