# Роли и выбор процедуры

**OCMI 1.2.3, редакция правил 2026-10-13**

После [RULES](RULES.md) выбери ровно свою процедуру; остальные открывай только для относящегося к ним действия.
Входы из действующего START/контракта обязательны независимо от этого маршрута.
Правила действуют для новых назначений/явных ревизий; выданные пакеты не переписываются.

| Роль | Процедура | Контекст после правил |
| --- | --- | --- |
| Оркестровщик | [Подготовка и приёмка](roles/coordinator.md) | INDEX, BRIEF, актуальные STATE/handoff и нужная часть PLAN |
| Исполнитель | [Выполнение и Result](roles/worker.md) | Адресный START, фиксированный Contract, свой Result и перечисленные входы |
| Консультант | [Ответ по источникам](roles/consultant.md) | INDEX и источники вопроса |

[PLAN](PLAN.md) — единственная очередь; [handoff](tasks/orchestration/HANDOFF.md) — назначения.
[Протокол карточки](TASK-PROTOCOL.md) — форматы, не новое назначение.
Число слотов/модели задаёт проект; один владелец на задачу, пути и ресурсы не конфликтуют.
Новая копия не изолирует процессы/секреты. Среда и разрешения проверяются отдельно.
Создание чатов, сообщения, commit/публикация, production, фоновые задачи и смена моделей
не разрешаются комплектом; по умолчанию передача ручная.
