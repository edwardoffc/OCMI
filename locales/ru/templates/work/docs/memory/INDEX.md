## Задачи

Задачи ещё не выданы. Оркестровщик добавляет ID, ссылку и статус из PLAN после создания карточки. Приоритет хранится только в PLAN; новая беседа по задаче использует прежнюю карточку.

Ссылки на человеческие документы, отчеты и архив добавляются после проверки их наличия. Не загружать всё по всем ссылкам на старте.
Процедуру выбирать по своей роли через ORCHESTRATION; карту/уроки открывать по текущей области.
При принятом уроке добавить ссылку на руководство или созданный локальный LESSONS;
кандидаты остаются в карточках, отдельная очередь не нужна.
