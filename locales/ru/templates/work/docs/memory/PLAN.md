# Канонический план

Шаблон. При установке заполнить из текущего запроса и существующих источников, сохранив ID открытых задач. Если действующий план уже есть, использовать его и адаптировать ссылки вместо второго плана.

| ID | Результат и критерий | Зависимости | Приоритет | Статус | Карточка / доказательство |
| --- | --- | --- | --- | --- | --- |

Статусы: draft → ready → running → review → accepted → integrated.
blocked обозначает конкретное препятствие, не завершение. Переход в review — сдача исполнителя, accepted — решение оркестровщика, integrated — проверенный перенос результата. Выпуск во внешнюю среду учитывается отдельно и не следует автоматически из integrated.
