# TASK-ID: цель

**OCMI 1.3.4, редакция правил 2026-10-13**

Шаблон, не назначение. Создать tasks/<id>/HANDOFF.md; сохранить точные заголовки
и поля существующего экспортёра. [Протокол](../TASK-PROTOCOL.md), [процесс](../ORCHESTRATION.md).
Полный формат; ограниченная обратимая задача низкого риска может использовать [SMALL-TEMPLATE](SMALL-TEMPLATE.md)
после проверки применимости главным. Старые пакеты/checkers задним числом не сокращаются.

## Contract

- Один интегрируемый результат / потребитель / критерий завершения / зависимости:
- Scope и исключения; внешние предпосылки, unknown и необходимое решение:
- Реальные форматы, версии, ID/единицы поддерживаемых в задаче протоколов/режимов:
- Первый сквозной путь через callers; совместимость старых данных, остановка/перезапуск и отказы по риску:
- Baseline commit с тестами либо проверяемый snapshot; непринятый WIP; ссылка на неизменяемый контракт:
- AllowedPaths и текущий HANDOFF (только тело Result); проверена вся цепочка callers/schema/config/CI/среды:
- ProtectedPaths/SHA256: тесты, fixtures, runner/config, Contract/Acceptance/JSON; нет противоречия scope:
- Минимальный контекст: точные версии правил/входов, пути/разделы/символы; доступны новому чату:
- Достаточные существующие приёмочные проверки, утверждённые главным ДО выдачи; новые тесты для пробелов;
  baseline/валидный контроль и причинность результата:
- Профиль среды: ссылка на STATE/runbook, версия клиента/условия/дата evidence; неизвестное явно;
- Checks: cwd, реальные команды, среда, expected/skips, формат Result и действующий checker:
- Для checks: зависимости/fingerprints, достаточность, условия повторов/reuse; финальная интеграционная проверка:
- Пробелы/риски для собственных тестов/oracle/mutations, если нужны:
- Назначение: один слот/чат, основной контекст (копия, ветка при наличии), фактическая модель/усилие:
- Временные ресурсы задачи или «нет»: путь/ветка/процесс; владелец; событие завершения; keep/archive/remove/transfer; основание уже разрешённой уборки:
- Полномочия; источник текущих бюджетов/условий остановки; эскалация:
- Ревью по процессу; что означает принято/интегрировано, отдельные условия выпуска:

## Result

Не начато. Заполняет назначенный исполнитель; поля сдачи — в протоколе.
Статус/дата; baseline/полный diff; выполнение матрицы; команды/exit codes/pass-fail-skip,
зависимости/логи, protected hashes, reuse/причины повторов; риски/непроверенное;
остаток/процессы и ссылки на сохранённый WIP; предложения для карты и кандидат в урок: область/условие/действие/evidence/ограничения.
По ресурсам задачи: путь/ветка/процесс, владелец, состояние и нужное сохранение либо «нет»/unknown.
Время/расход/модель — фактические с источником и областью либо unknown.
Счётчики извлечь из логов, не повторять suite ради оформления; выданный checker обязателен.

## Acceptance

Не проводилась. Только главный:
- Полное первое ревью; список ID/воспроизведение/влияние/результат/проверка и класс замечания.
- После доработки — delta, прежние findings и затронутые связи; расширение по риску.
- Перед следующим существенным возвратом — класс причины, сохранённый лог падения/WIP, гипотеза, изменённый подход,
  следующая диагностика и ожидаемое новое evidence; затронутая проверка перед обоснованным полным повтором.
- Решение/дата, принятая версия, интегрированная версия/общие проверки либо конкретная предпосылка.
- Возвраты/причины, повторные checks/причины, подтверждённый reuse, корректировки отчёта без подделки Result.
- Доступные время/расход до интеграции с источником/областью; неизвестное не оценивать.
- Урок: принят/отклонён с причиной; локальное место/источник и статус, без автоматического глобального переноса.
- cleanup: done либо pending; остаток/причина, владелец, следующее действие/условие проверки; для сохранённого — назначение, условие хранения и доступ/восстановление. Без ресурсов: done — временные ресурсы не создавались.
- Затронутые факты памяти и ссылки актуализированы; исторические пакеты сохранены; изменение среды проверено адресно.
- Новый независимый scope — PLAN; критический риск блокирует приёмку. Выпуск отдельно.
