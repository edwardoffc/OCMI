# Поиск до новой реализации

Применяйте, когда задаче нужна возможность, а наличие готовой реализации неизвестно. Если актуальные доказательства уже указывают нужное место, новый поиск не требуется.

Прочитайте выбранную запись карты кода и обязательные входы, затем ищите символы, потребителей, тесты и манифесты пакетов внутри назначенного корня. Проверяйте настоящего потребителя и совместимость, а не похожее название функции. Уточняйте неполный поиск в разрешённой области; не исключайте тесты и не объявляйте отсутствие по обрезанному выводу.

Только если локальный поиск оставил пробел, оцените внешний пакет/сервис при разрешённом доступе. Сравните API, поддержку, лицензию, зависимости и эксплуатационную стоимость с небольшой локальной реализацией. Актуальные API проверяйте по первичным документам; не передавайте в поисковые запросы закрытый код, пути, клиентские данные и секреты. Находка пакета не разрешает установку или новый сетевой доступ.

Верните путь/символ и доказательства либо краткое решение «использовать/расширить/написать» с существенными ограничениями и пробелами. Сохраните в существующем Result/Acceptance, без второго реестра.

Если инструменты недоступны, укажите непроверенную область и используйте переданные источники, не выдумывая результатов. Исследователь или глобальный поиск не запускаются автоматически.
